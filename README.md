# Audio Exercise
A starter project for exploring audio in MonoGame.

The associated video tutorial can be found at [https://youtu.be/AllNImteUEw](https://youtu.be/AllNImteUEw)

Assets used in this game and thier associated licenses are described in [ASSETS.md](ASSETS.md)

This tutorial was created for the CIS 580 - Foundations of Game Programming course offered by the [Department of Computer Science](https://cs.ksu.edu) at [Kansas State University](https://ksu.edu)
